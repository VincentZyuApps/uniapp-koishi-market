KOISHI PLUGIN

@saltnya/image-selector

@saltnya/koishi-plugin-image-selector

支持随机图片发送和用户存图功能。包含别名文件夹匹配、多种存图方式、自定义文件名模板和智能文件类型检测等特性。同时支持群组隔离、关键词/别名管理、删除图片、上传权限控制及多种触发模式。
