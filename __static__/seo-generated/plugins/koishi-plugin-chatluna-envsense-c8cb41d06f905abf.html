KOISHI PLUGIN

chatluna-envsense

koishi-plugin-chatluna-envsense

ChatLuna 环境感知工具集：为 Agent（plugin）模式按需提供群概况、成员、公告、荣誉、精华、打卡、头像与 QQ 资料卡、获赞等只读查询，并支持读取合并转发（聊天记录）与修复 chatluna 对引用合并消息的处理；图片取回真实字节再交给模型。另有默认关闭的主动工具（bot 以自己身份在当前群打卡、给当前发言人/私聊对象点赞），只作用于当前会话并受白名单与每日一次限制。仅 NapCat(onebot11) 生效。
