KOISHI PLUGIN

ll-sentinel

koishi-plugin-ll-sentinel

李浅浅自用插件。端点可用性值守：对配置的 host:port 做 TCP 建连探测，判断服务是否在监听。首次探测只记基线不推送，之后需连续 N 次确认「不通 → 通」才推送提醒；探到通时立即复探而不干等轮询周期，因此检测延迟可压到一个周期以内。支持多端点、探测间隔/超时/确认次数、状态查询与历史翻转记录。监测目标需在配置中自行填写。
