# 响应式 UI 验收清单

本轮只修改源码。开发服务和 Web H5 发行由维护者在 HBuilderX 中执行；不要用 CLI 构建替代，不手工修改发布产物。

## 布局约定

- 手机断点为 600px，平板为 601–900px，桌面为 900px 以上。
- 筛选面板默认关闭，所有尺寸统一使用 320px 宽度及 calc(100vw - 64px) 最大宽度约束，右侧至少留出 64px 遮罩，始终覆盖而不挤压列表。
- 手机与 PC 均可点击遮罩、顶部关闭或底部“完成”关闭面板，保留已选条件；H5 还可按 Escape 关闭。
- 桌面正文、辅助信息、区块标题、页面标题分别为 14、13、18、23px；手机正文和输入框 16px、辅助信息 13px、页面标题 22px。
- 手机市场单列，其他尺寸根据实际列表宽度计算列数，最多九列，每页五行。

## HBuilderX 运行后检查

在 320、375、390、440、600、768、900、1024、1440px 下检查市场、详情、设置和 Agent 页，补充手机横屏、深浅主题和系统大字体。

- 打开/关闭抽屉时，列表宽度、列数、页码及滚动位置不变；背景不可滚动。
- 在 320、375、390、440px 视口下，抽屉分别为 256、311、320、320px 宽；桌面保持 320px。检查最窄面板的标签、数量、排序箭头和操作按钮不溢出。
- 手机抽屉顶部关闭、底部完成始终可达，中间筛选内容可滚动到底。
- H5 键盘焦点限制在打开的抽屉内，关闭后回到入口；输入文字时方向键不会翻页。
- 工具栏正常占位，第一张卡片和错误提示不被覆盖；上一页、下一页及空结果页码正确。
- 长插件名、长包名、评分、下载量、版本、多个搜索标签和长 URL 不撑破页面。
- 筛选、排序、刷新取消、错误重试、详情跳转、设置持久化、Agent 提示词生成与复制行为不变。
- 设置和 Agent 页的返回/主题与标题在手机分行；长链接可换行，复制按钮不被挤压。
- 详情统计区手机一列、平板两列、桌面四列；维护者、服务标签和富文本无整页横向溢出。
- 微信、QQ 小程序的状态栏、胶囊及底部安全区不遮挡控件；弹出键盘后仍可编辑、滚动和操作。
- 内容更新、横竖屏切换后，自定义滚动条能正确反映可滚动范围。

## 验证边界

源码语法检查不等于 HBuilderX 编译和真机验收。需要维护者提供运行地址或新截图后，继续验证实际渲染；本轮不更新版本、不提交、不推送、不部署。
