## 🚀 GitHub Action 部署

> **注意**：只有 commit message 中包含 `pub page` 时，才会触发 GitHub Pages & Cloudflare Pages 部署流程。  
> 手动 `workflow_dispatch` 触发不受此限制。

## 📟 Git 命令行操作
```shell
python scripts/bump.py -v x.y.z-beta.w -c yyyymmdd
# HBuilderX gui界面左上角： 发行 -> 发行到WebH5
python scripts/generate_cf_redirects.py
git add -A
git add -f unpackage/dist/build/web/
git status --short
git diff HEAD --stat
git status unpackage/dist/build/web/
git ls-files unpackage/dist/build/web/
git commit -m "pub page: some commit messages..." # 如果想要更新github page、cloudflare page和gitlab page的话
git push github main
git push gitee main
git push gitlab main
git push codeberg main
```
